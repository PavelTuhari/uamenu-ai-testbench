# 9. Заказы

У кассы два разных «заказа», и проверяются они по-разному.

| | Заказ столовой / ресторана / доставки | Заказ товара поставщику (Alisca) |
|---|---|---|
| Где | окно «Заказы» / «Comenzi» (`order.cpp`, `Tforder`) | продажная форма, тип документа из «Выбор операции» (раздел 3) |
| Данные | `VMDB_COMENZ_RESTAURANT`, `VMDB_COMENZD` | `TMDB_COMENZ` с `DOC_TYPE` заказа, строки `TMDB_COMENZD` |
| Итог | чек после закрытия заказа | документ без печати, бэк-офис делает из него заказ поставщику |
| Вариант | UNIREST (`Style` DOSTAVKA, PRODZACAZ, RESTH, TS) | CASSA / TS с `ShowMenuSelDocType=true` |

## 9.1 Заказ товара поставщику (тип документа)

- [ ] В `VMS_SYSS cod=120` есть тип «Заказ» и кнопка `CreateSpecialDoc` с
      этим типом (раздел 3.1). Нет — «не применимо» с записью.
- [ ] «Выбор операции» → «Заказ»; предупреждение «Выбран режим: Заказ».
      Снимок `ord-01-doctype`.
- [ ] Позиции с нужным количеством (без цены продажи смысл в количестве),
      `F11`.
- [ ] SQL: `doc_type` = тип заказа, строки с количеством.
- [ ] Бэк-офис: заказ поставщику появился (запрос владельца).

## 9.2 Заказ столовой: создание

- [ ] Меню «Заказы». При `PinOfficiant=true` — PIN официанта. Снимок `ord-02-list`.
- [ ] `Insert` → новый заказ (стол, официант, число гостей).
- [ ] Добавить позиции (`addAction1`, `order.cpp:473`) — три блюда, одно с
      количеством 2.
- [ ] SQL: `select * from vmdb_comenzd where nr_comand = <номер>` — три строки.

## 9.3 Изменения

- [ ] Дубликат заказа (`yunirest.Dubl`) → новый номер, те же позиции.
- [ ] Дисконтная карта к заказу (`disc_unirest.pay_disc_card`) → скидка в итоге.
- [ ] Разделить счёт (`yunirest.complet_razbiv`) → два счёта на тех же гостей.
      Снимок `ord-03-split`.

## 9.4 Закрытие

- [ ] «Закрыть» → `close_comand` (`order.cpp:855`): `yunirest.can_close`
      разрешил, `complet_tmdb_beg` создал чек, `throw_off_order` снял заказ.
- [ ] Оплатить чек (раздел 5), напечатать → файл чека с позициями заказа.
- [ ] Заказ, который закрыть нельзя (например, неоплаченный долг) → отказ с
      причиной от `can_close`.

**Ожидается:** закрытый заказ превращается ровно в один чек; открытых
копий не остаётся.

## 9.5 Доставка (`Style=DOSTAVKA`)

- [ ] Новый клиент из заказа → «отправить в бухгалтерию»
      (`unirest_link_util.send_client_buh`, `order.cpp:2031`) → клиент есть
      в бэк-офисе.
- [ ] Время оплаты и адрес в заказе печатаются в чеке.
