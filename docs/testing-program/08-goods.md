# 8. Виды товара: простой, весовой, с размером и длиной

## 8.1 Простой товар

- [ ] Штрихкод EAN-13 → позиция, цена из `VPR_PRICES`.
- [ ] Тот же товар второй раз → по настройке `Insert_tovar`: вторая строка или
      прибавка количества; записать.
- [ ] Товар с несколькими штрихкодами (разные упаковки) → каждый находит
      тот же `SC`.
- [ ] Товар с несколькими совпадениями → окно выбора (`uSeveralTovar`,
      `ShowModalSeveralTovar`, `dtmod.cpp:3479`). Снимок `goods-01-several`.

## 8.2 Весовой товар

- [ ] Штрихкод весов (префикс и вес в коде) → количество = вес из штрихкода
      (`bWeigth` в `Find_tovar`).
- [ ] `Ctrl+1` «Взвесить» (`Scales.cpp`, `ScalesI.cpp`; драйверы
      `Drivers\Scales\`) с подключёнными или эмулированными весами → вес в
      поле количества. Без весов — «не применимо».
- [ ] Цена позиции = вес × цена за кг, округление как в чеке.

## 8.3 Товар с размером и длиной (SIZES)

Работает в режиме штрихкодов Aridon: `BarCodeAridon=true`, `UseSzLen=true`
(по умолчанию true). После выбора из списка совпадений касса зовёт
`DTM->EnterSzLen(sc)` (`dtmod.cpp:2426`, `:9469`) → форма `TSzLen`
(`uszlen.cpp`) с полями **размер** и **длина**, затем
`Bon.EnterSzLen(:pcod,:p_sz,:p_len)`. При `CustomBarcodesMode=ZOR` поле
длины подписано «Цвет». **Ширины у товара в кассе нет** — поле с таким
смыслом в исходниках отсутствует; если нужна ширина, это задача бэк-офиса
и доработки `TSzLen`.

- [ ] Сканировать артикул одежды (например `CARDIGAN`) → список размеров;
      выбрать → форма размер/длина. Снимок `goods-02-szlen`.
- [ ] Оставить размер пустым → отказ «Trebuie completata marimea!».
- [ ] Ввести размер `L`, длину `100` → позиция; в чеке размер и длина
      (в файле чека и SQL: `select * from tmdb_comenzd where nrdoc=<номер>`
      — поля размера и длины заполнены).
- [ ] Ткань: длина `2.5` → количество 2.5, цена за метр × 2.5.
- [ ] Режим `ZOR` (если используется): поле «Цвет» принимает текст.
- [ ] Возврат размерного товара (`F3`) — спрашивает размер снова, возвращает
      тот же.

**Ожидается:** без размера продать нельзя; размер и длина доходят до базы и
до чека; ширина — в акт как «нет в кассе».

## 8.4 Цена и скидка товара

- [ ] «Изменить цену» (`Ctrl+F2`, если включено) → цена меняется с правом;
      без права — отказ.
- [ ] Акционная цена (`Цена по справ.` vs `Цена продажи` в сетке) показана и
      в чеке применена акционная.
