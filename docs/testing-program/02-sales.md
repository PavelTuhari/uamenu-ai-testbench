# 2. Продажи: чек от открытия до печати

Форма продаж — `Tfhvbb` (`Uhvbb.cpp`), логика — `TDTM` (`dtmod.cpp`).
Поиск товара: `bon.Find_tovar`, добавление: `bon.Insert_tovar`
(`dtmod.cpp:2327`, `:2437`). Клавиши — из меню «Действия» (`fMenu.dfm`).

## 2.1 Простой чек

- [ ] Новый чек (после печати касса открывает его сама: `NewBon()`,
      `dtmod.cpp:3357`). `selftest: newcheck`.
- [ ] Сканировать штрихкод товара → позиция в чеке, количество 1.
      `selftest: item,<код>,1`.
- [ ] Ввести количество **до** сканирования в поле `Cant.` → позиция с этим
      количеством. `selftest: item,<код>,3`.
- [ ] Клавиша `/` — курсор в количество в сетке; изменить, Enter.
- [ ] `Ctrl+Num+` / `Ctrl+Num-` — прибавить и убавить введённое число
      (`UpdateCant`, `Uhvbb.cpp:1448`).
- [ ] Снимок `sale-01-items`. `selftest: shot,sale-01-items,check`.
- [ ] Сумма внизу равна сумме позиций.

**Ожидается:** позиции и суммы верны; количество меняется без пересканирования.

## 2.2 Ручной ввод штрихкода

- [ ] Клавиша `*` переключает в поле ручного ввода (`edBarCode`); ввести код,
      Enter.
- [ ] Ввести несуществующий код → сообщение «не найден», чек не изменился.
- [ ] Ввести код с лишним символом при `CheckBarcode=true` → отказ;
      при `BarcodeAddon=true` расширенный код принимается.

**Ожидается:** ошибки ввода не ломают чек и не добавляют «пустых» позиций.

## 2.3 Скидка на позицию

- [ ] Встать на позицию, `Ctrl+F3` → форма скидки (процент или сумма,
      `Uadddiscont`; нужен `EnderRedus=true`).
- [ ] Ввести 10 % → цена позиции пересчитана, в базе
      `Disc_Unirest.ADD_DISCONT` (`dtmod.cpp:9548`).
- [ ] Снимок `sale-02-discount`.

**Ожидается:** скидка видна в чеке и на виртуальном чеке после печати.

## 2.4 Отмена чека

- [ ] `F5` → при `CancelCheckByPIN=true` запрос PIN; ввести → чек пуст.
      `selftest: cancel`.
- [ ] С `BlockCancel` (например, во время открытой мультиоплаты) → отказ с
      сообщением.
- [ ] SQL: у отменённого чека `state` отменён, позиций нет.

**Ожидается:** отмена требует права; отменённый чек не попадает в итоги.

## 2.5 Отложенный чек

Видно при `ShowMenuDeferred=true`.

- [ ] Набрать чек, `F7` «Отложить» → чек исчез, номер записан.
- [ ] `Ctrl+A` список отложенных — чек в списке. Снимок `sale-03-deferred`.
- [ ] `F8` вернуть по номеру → позиции на месте.
- [ ] Попробовать Z-отчёт при отложенном чеке → отказ
      (`Unirest_Util.CHECK_RESERV_Z`, раздел 6).

**Ожидается:** отложенный чек восстанавливается полностью; Z при нём невозможен.

## 2.6 Возврат

- [ ] `F3` режим возврата (`ToggleStateReturn`, `dtmod.cpp:10924`;
      нужен `UseReturn=true`) → индикатор режима на форме. Снимок.
- [ ] Сканировать товар → позиция с отрицательной суммой; оплата возвращает
      деньги. `selftest: return`.
- [ ] `F9` возврат чека целиком (`UseWholeReturn=true`): ввести номер чека из
      2.1 → все позиции с минусом (`bon.rest`, `dtmod.cpp:4349`).
- [ ] Напечатать → на виртуальном чеке слово возврата и минус.

**Ожидается:** суммы возврата равны исходным; номер основания в чеке.

## 2.7 Печать и повтор

- [ ] `F12` печать → файл в `VirtualCheckPrinter\…\VPCheck_*.txt`,
      касса открыла новый чек. `selftest: print`.
- [ ] Открыть файл: шапка, позиции, итог, способ оплаты, номер.
      Снимок `sale-04-receipt`.
- [ ] `Ctrl+R` повтор последнего чека → второй файл с тем же содержимым.
- [ ] `Ctrl+W` просмотр чеков (`ShowMenuPreview=true`) — чек в списке.
- [ ] `F11` сохранить чек без печати → в базе есть, на принтере нет.

**Ожидается:** содержимое файла чека совпадает с экраном и с
`TMDB_COMENZD` по позициям и сумме.

## 2.8 Консультант, клиент, информация о товаре

- [ ] `F1` выбор консультанта (`ConsultEnabled=true`) → имя в чеке.
- [ ] «Выбрать клиента» / «Очистить клиента» из меню → клиент в шапке чека.
- [ ] «Информация о товаре» → остаток и цена без добавления в чек.

**Ожидается:** все три не меняют позиции чека.
