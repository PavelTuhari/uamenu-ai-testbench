# 7. Встроенные отчёты фронта («Отчёты» / «Rapoarte»)

Список отчётов не в коде, а в таблице `TMDB_REPORTS` (`COD`, `DENUMIREA`,
`TEMPLATE`, `FUNCTION`, `AUTOHIDE`). `FillReportsMenu` (`fMenu.cpp:1630`)
строит пункт на строку; клик → `Totc` (`reports.cpp`): выполняет
`begin <FUNCTION>; end;` с фильтрами из `VMDB_REPCFG` (бармен, официант,
блюда, состояние, тип оплаты, тип счёта, номер комнаты, категория,
смена) и рисует шаблон из `TEMPLATE_DIR` через `MakeUniReport`.
Меню видно при `ShowMenuReports=true`.

## 7.1 Состав

- [ ] SQL: `select cod, denumirea, template, function, autohide from tmdb_reports order by cod`
      — список в акт целиком.
- [ ] Пункты меню «Отчёты» совпадают со списком (кроме `AUTOHIDE`).
      Снимок `rep-01-menu`.
- [ ] Для каждого `TEMPLATE` файл есть в каталоге шаблонов
      (`Templates\*.fr3`); отсутствующие — в акт.

## 7.2 Каждый отчёт

Для **каждой** строки `TMDB_REPORTS`:

- [ ] Открыть, выставить фильтр «сегодня», выполнить. Снимок `rep-<cod>`.
- [ ] Отчёт построился без ошибки Oracle; цифры дня совпадают с X
      (раздел 6) там, где отчёт о выручке.
- [ ] Печать в файл или на виртуальный принтер — если отчёт печатный.
- [ ] Пустой период → отчёт пустой, а не ошибка.

**Ожидается:** ни один отчёт не падает; суммы сходятся с X и «Итогами».

## 7.3 Создание отчёта

- [ ] «Создать новый отчёт» (`N7`, `fMenu.cpp:179`) → строка в `TMDB_REPORTS`;
      задать тестовые `FUNCTION`/`TEMPLATE`, увидеть пункт в меню.
- [ ] Удалить тестовую строку, проверить SQL, что её нет.

## 7.4 «Итоги»

- [ ] Меню «Итоги»/«Total» (`casa.cpp`): приход («Intrari»), расход,
      остаток в кассе. Сверить с внесением/изъятием раздела 5.8 и X.
      Снимок `rep-02-total`.
