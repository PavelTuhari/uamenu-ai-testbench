# 10. Товар не сканируется: поиск по названию, артикулу, коду, цене

Клавиши продажной формы (`Tfhvbb::FormKeyPress`, `Uhvbb.cpp:1796`),
работают при `ManualSearchDenum=true` (`Uhvbb.cpp:1875`) и соответствующих
`ParamSearchBy*Enabled`:

| Клавиша | Поиск | Режим `Find_tovar` |
|---|---|---|
| `+` | по названию | `smDenumirea` |
| `Shift` + `+` | по артикулу (`FindTovarByArticol` меняет их местами) | артикул |
| `-` | по коду | код |
| `Shift` + `-` | по короткому коду (`FindTovarByShortCode`) | короткий код |
| `)` | по цене (`SearchByPriceKey`) | цена |

Окно — `TfPartDenum` (`partDenum.cpp`), результат идёт в
`FindInsertTovar(text, qty, NULL, mode)`; несколько совпадений →
`uSeveralTovar`. **`F3` — это не поиск, а режим возврата.**

## 10.1 Повреждённый штрихкод

- [ ] Сканировать нечитаемый код (заклеить часть) → «не найден», чек цел.
- [ ] `+` → ввести часть названия, например `DENIM` → список совпадений
      (`SORTI DENIM C` и прочие). Снимок `find-01-name`.
- [ ] Выбрать нужный → позиция в чеке с правильной ценой.
- [ ] Ввести количество до поиска → учтено.

## 10.2 По артикулу и коду

- [ ] `Shift`+`+` → артикул `LM289` → `SORTI TRICOTAJ LM289`.
- [ ] `-` → внутренний код `5649` → тот же товар.
- [ ] `Shift`+`-` → короткий код (если у кассы есть `FindTovarByShortCode`).

## 10.3 По цене

- [ ] `)` → `350` → все товары по 350.00; выбрать. Снимок `find-02-price`.

## 10.4 Граничные случаи

- [ ] Пустая строка поиска → ничего не добавлено.
- [ ] Название кириллицей и латиницей — оба находят (кодировка базы
      `CL8MSWIN1251`; на сервере с нерусской локалью см. `encoding.md`).
- [ ] Тысяча совпадений (`%`) → окно открывается за приемлемое время,
      записать секунды.
- [ ] `ManualSearchDenum=false` → клавиши ничего не делают.

**Ожидается:** любой найденный товар попадает в чек тем же путём, что и
сканированный (`Insert_tovar`), с той же ценой и скидками.
