# 5. Оплаты: наличные, карта банка, MIA, подарочная карта, мультиоплата

## 5.1 Наличные и сдача

- [ ] Чек на 343.95; в поле оплаты (`edPay`) 350, Enter. `selftest: pay,350`.
- [ ] Сдача 6.05 на экране и в файле чека.
- [ ] `pay,total` — точная сумма, сдача 0.
- [ ] Меньше суммы → отказ или долг по настройке; записать.

**Ожидается:** сдача считается верно; при `PrintAfterPay=true` Enter в поле
оплаты сразу печатает (`Uhvbb.cpp:1474`).

## 5.2 Безналичная оплата переключателем

- [ ] `Shift+Z` (`InvertPayType`) → признак безнала в шапке. Снимок.
- [ ] Напечатать → в файле чека способ оплаты «безнал».

## 5.3 Банковский POS-терминал

`Ctrl+E` → `TermCard` → `DTM->POSTermPay` (`dtmod.cpp:11642`). Драйверы
в `Drivers\POSTerm\`: IP/Verifone, Ingenico, BPAY, VF, APB-socket. Ключи:
`POSTermEnabled`, `POSTermSocket`, `POSTermSocketHost/Port` (8882),
`POSTermPort` (9999), `POSTermIngenico`, `POSTermLog`,
`POSTermPrintRCPTBefore`, `POSTermPrintRCPTAfterAsNewCheck`.

- [ ] Терминал или эмулятор подключён; «POS Проверка связи» (`Ctrl+Shift+T`)
      → успех. Снимок `pay-01-pos-conn`. Без терминала — весь 5.3 «не применимо».
- [ ] Чек, `Ctrl+E` → запрос к терминалу, подтверждение → чек закрыт картой.
- [ ] Слип печатается до или после чека по `POSTermPrintRCPTBefore` /
      `…AfterAsNewCheck` — записать, как настроено, и что вышло на
      виртуальный принтер.
- [ ] «POS Копия чека» (`Ctrl+Shift+C`) → копия слипа.
- [ ] «POS Отчет X» / «POS Отчет Z» (`Ctrl+Shift+X` / `Ctrl+Shift+Z`) →
      отчёт терминала; Z только в конце дня.
- [ ] Отказ терминала (вынуть карту, отменить на пинпаде) → касса показала
      отказ, чек **остался открытым**, оплаты нет.
- [ ] Журнал `POSTermLog` — записи запроса и ответа без PAN целиком.

**Ожидается:** успех и отказ оба обрабатываются; чек не закрывается без
подтверждения терминала.

## 5.4 MIA (оплата по QR)

Меню «MIA» (`mItemMIA`), форма `uMIAPayments.cpp`, REST `uMIARest.cpp`:
`/v2/auth/token`, `/v2/mia/qr`, `/v2/mia/qr/{id}`, `…/cancel`,
`/v2/mia/test-pay`. Режимы `MIAMode`: `printer` (QR на чеке), `rest`,
`simulate`. Секреты `MIAClientSecret`, `MIAApiSecrect` — только пометки
`@secret:` (раздел секретов).

- [ ] `MIAMode=simulate`: чек, MIA → QR на экране, «оплачено» без сети.
      `selftest: mia,<сумма>`. Снимок `pay-02-mia-sim`.
- [ ] `MIAMode=rest` с `MIAUseTestPay=true` на тестовом контуре: токен
      получен, QR создан, `test-pay` подтвердил. `selftest: miarest,<сумма>`.
- [ ] Таймаут (`MIAPollTimeoutSec` маленький, не платить) → касса отменяет QR
      (`/cancel`), чек открыт.
- [ ] Повторный запрос после таймаута — новый QR, старый не оплачивается.
- [ ] В файле чека — признак оплаты MIA и id операции.

**Ожидается:** оплата отмечается только по подтверждению; таймаут безопасен.

## 5.5 Мультиоплата

`Ctrl+K`, форма `MultiPayments.cpp`, таблица `TMDB_COMENZ_PAY`, справочник
`PAY_TYPES`. Нужен `MultiPayment=true`.

- [ ] Чек на 500; `Ctrl+K` → окно; 200 наличными, 300 картой.
      `selftest: multipay` / `addpay,<id>,200` / `closemultipay`.
      Снимок `pay-03-multi`.
- [ ] `F12` во время открытой мультиоплаты → отказ (`fMenu.cpp:325`).
- [ ] Закрыть мультиоплату → чек печатается с двумя строками оплаты.
- [ ] SQL: `select pay_id, suma from tmdb_comenz_pay where nrdoc = <номер>` — две строки.
- [ ] Ограничения `multipaymentRestrictedPayIDList` — запрещённый метод не
      предлагается.

**Ожидается:** сумма частей равна чеку; чек нельзя напечатать до закрытия окна.

## 5.6 Подарочная карта и сертификаты

- [ ] `Ctrl+G` (`UseCardPodaroc=true`) → режим оплаты подарочной картой,
      сканировать карту (тип в `vms_dcard`) → сумма списана.
- [ ] `Ctrl+L` сертификаты (`Certificates.cpp`) → выдать сертификат,
      погасить его в следующем чеке.
- [ ] Остаток карты `F2` «Обновить остаток».

## 5.7 Бонусы и купоны лояльности

- [ ] Приложить карту: `selftest: card,<номер>,1` (дисконтная) или `,6`
      (столовая). Снимок `pay-04-card`.
- [ ] `Ctrl+Shift+F6` списать бонусы: `selftest: bonus,max`.
- [ ] Купон: `selftest: coupon,<штрихкод>`; выдача `couponsell`; справка `couponinfo`.
- [ ] POS API лояльности: `selftest: posapi,member,<карта>` / `posapi,txn` /
      `posapi,void,test` — ответы в `APILog.txt`.
- [ ] Кошелёк: `walletshow`, `wallet,<баланс>,<ставка>`, `walletapply`.

**Ожидается:** списание не превышает баланс; `void` возвращает начисление.
