# 12. Акт

Акт собирается кнопкой «Выгрузить акт» на странице: в него попадают все
разделы с отметками шагов. Руками дописываются таблица результата и
список «не проверяли».

## Шапка

| | |
|---|---|
| Касса | `UAMenu v.<версия>`, `PosID`, вариант (CASSA / UNIREST / TS / SIZES / SELF) |
| База | схема, сервер, версия Oracle, `select count(*) from user_objects where status='INVALID'` |
| Машина | Windows, `ACP` (должно быть 1251), `NLS_LANG` клиента |
| cantina.ini | `sha256` из `cantina_ini.get_hash()` и id версии в бэк-офисе (`v_cantina_ini_current`) |
| Принтер | `VirtualFP`; реальный — не подключали |
| Дата, кто | |

## Не проверяли

Перечислить словами: оборудование, которого не было; варианты кассы,
которых нет на стенде; разделы «не применимо» с причиной.

## Дефекты

Для каждого: шаг, ожидалось, получено, снимок, воспроизводимость, запись
в `selftest.log` / `license.log` / `APILog.txt`, если есть.

## Уборка

- [ ] Тестовые чеки отменены или оставлены в тестовой базе — записать номера.
- [ ] Временные изменения цен возвращены (раздел 1.2), SQL подтверждает.
- [ ] Контекст `INVENTR` снят, `cantina.ini` стенда сохранён (`ini save`).
